# Pencils to Pixels: Reimplementing SDEdit
by: Rio Voss-Kernan (rvossker), William Jarvis (wjarvis10), and John Perdue (jperdue21)

SDEdit is a famous paper and method in deep learning which enables image generation or editing from an input image.
In our implementation, we create a model that can turn hand-drawn sketches of flowers into photorealistic flower images.
See the writeup or poster in this repo for a full explantion of the project.
